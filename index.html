Setup note for the form administrator (Rashid) — tap to expand

This form writes to a Google Sheet through a Google Apps Script Web App. Before sharing this form:

  1. Create a Google Sheet for responses.
  2. Open Extensions → Apps Script, paste the backend code provided separately, change ADMIN_PASSWORD to something private, and deploy it as a Web App (Execute as: Me, Who has access: Anyone).
  3. Copy the deployment URL and paste it as GAS_URL near the top of the <script> section of this file, replacing "PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE".
  4. Re-open this file — submissions will then be appended to your Sheet automatically, each with a unique Form Number, and a PDF copy will download to the teacher's device on every submission.

Teachers can search their own CNIC or Form Number above to re-download their PDF at any time. Editing an already-submitted record is only available from the Admin Panel (linked in the footer).

Until GAS_URL is set, the form will still let a teacher preview and download the PDF, but it cannot save the row to Google Sheets, search previous submissions, or unlock the admin panel.
